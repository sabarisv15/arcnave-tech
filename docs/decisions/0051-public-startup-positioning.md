# ADR-0051: Public startup positioning for college teams

- Status: accepted from the owner's 2026-09-28 request and factual confirmations.
- Date: 2026-09-28

## Context

Google's Start Tier criteria explicitly ask for a digital-native technology startup with
a working MVP, clear business model, venture-funding intention, and a defined roadmap.
The prior public site explained the initial academic document workflows, but did not
identify an institutional payer or expose the broader development direction. Auth copy
spoke about generic ideas rather than the college product.

Reference checked: https://claude.ai/ presents product capabilities, plans, company,
policies, and account entry separately. ArcNave keeps this structural clarity with its
own brand and academic workflow content. The subscription and accreditation focus are
ArcNave's own decisions, based on the owner's statements, not copied reference behavior.

## Decision

1. The public site identifies ArcNave as an independent software startup serving college
   teams. It distinguishes the initial documentation workflows from longer-term faculty
   operations. Planned work is labeled as planned.
2. The institution is the intended subscription customer. Pricing is not yet fixed and
   the site does not imply active billing or revenue.
3. About states the owner-confirmed founding date, bootstrapped stage, and intention to
   seek venture funding within 12 months. Private billing and prior-credit facts stay out
   of public marketing copy.
4. The public workflow preview remains explicitly illustrative. Production MVP evidence
   requires a separate authenticated walkthrough; a landing-page illustration cannot
   substitute for that proof.
5. Auth language and static HTML metadata use the same campus product positioning.

## Consequences

The public website explains customer, payer, commercial intent, current product, and
roadmap without invented traction or shipping claims. Before a Google application or
live release, verify founder facts, billing/email alignment, actual production workflows,
and the current official program criteria.
