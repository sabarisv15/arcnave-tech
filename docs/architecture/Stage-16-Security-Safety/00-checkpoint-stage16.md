Once `app.company_id` has been set on a connection (also with `SET LOCAL`, and still after `RESET ALL`), Postgres returns `''`, not NULL; the plain `::uuid` cast then fails with 22P02 instead of returning 0 rows (reproduced on PostgreSQL 16 / 17; live LV-23: `context_state=empty`, 0 rows).

Input for ID-13 (migrator rights) in Phase 1.
