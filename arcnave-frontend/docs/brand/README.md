# arcnave brand – locked design pages (reference)

Exported 2026-10-14 from the design-track artifact "arcnave · Locked design"
(https://claude.ai/artifact/UcTovdqXxB6qcTvhF6StFv, version 1791993412-fa0f). Every page here is
**locked** by the owner; this folder is the source of truth for Phase 1 Item G (brand). Each
`*.dc.html` is a self-contained design page (inline SVG + styles) – open in a browser or read the
markup for exact hex colours, font names/weights, radii, spacing, logo SVG paths and animation timings.
`canvas.json` holds the board titles and order.

**Token sources, read these first:** `Brand-Locked.dc.html` (logo D1, palette, type), `V2-Tokens.dc.html`
(design-system tokens), `R16-Wordmark.dc.html` (wordmark L4 SVG, English + Tamil), `R16-Icons.dc.html`
(icons N2), `Logo-Live.dc.html` + `Brand-Motion.dc.html` + `States-Polish.dc.html` + `R14-Chat.dc.html`
(living logo, brand motion, AI-state animations), `Splash-v3.dc.html`.

Sample names and e-mails inside the pages (e.g. priya@psgtech.ac.in, no-reply@arcnave.in) are mock data.
