A separate zero-permission fetcher service is the infra half (Stage 19), later. Files: `services/webFetch.ts`, `tools/webExecutor.ts`, `tools/definitions.ts`, tests. Port source: `arcnave.in:backend/apps/fetcher/` (Python fetcher with SSRF rules).
- Option A (REWRITE the service in place): S-M · risk: low · breaks: `webFetch` unit tests that assert only hostname rules.
- Option B (port the Python fetcher as a separate service): L · needs infra; correct end state but not runnable without Terraform.
- Pick: A now; B at Phase 5.
