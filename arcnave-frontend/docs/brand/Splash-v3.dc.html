The 1 s version skips the papers: dots gather 0–0.65 s, wordmark 0.6–0.9 s. The dots stay as the logo. Android keeps a solid tile (system icon rules).
Rules
Never adds waitingThe quick splash only covers loading. If the app is ready early, it jumps to the end frame in 200 ms. Max 1 s.
Android 12+System splash = AnimatedVectorDrawable, under 1,000 ms (Android guidance). ~60 big dots, not 500, so the AVD stays light. Icon inside the 192 dp circle, wordmark as the bottom brand image.
iPhoneApple wants the launch screen plain and close to the first screen, no logo. So: plain background at launch, then the 3 s intro only on first open. No 1 s splash on iPhone.
Web (arcnave.in app)No splash. Sign-in already carries the brand motion. If the app shell takes over 400 ms, the 1 s quick version is the loader.
Reduce motionStill logo + wordmark, no dots. Same timing, no movement.
Same story everywhereSplash, sign-in, website hero and YouTube intro all use one idea: scattered → one point.
