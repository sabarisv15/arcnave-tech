### 4. Last tool round can end without an answer ("Answer cut off … every tool step")
- **Why pending:** root cause not confirmed; needs production logs.
- **Evidence:** `providers/gemini.ts:447-456` — if Vertex rejects function-calling `NONE` on the
  final round, the round is retried with tools on, and a call there ends as `tool_limit`
  (`gemini.ts:522`) with no answer.
- **How:** search Cloud Logging for `final round with function calling off was rejected`. If
  present, force an answer another way (e.g. drop `tools` from that request instead of
  `toolConfig`). Check the reference: Claude's final round has no tools (`anthropicVertex.ts`
  does the same).

### 5. Table tools are deferred behind `search_tools`

### 6. Silent model fallback (Invariant 1)

### 7. Auto-continue after `tool_limit`
- **Claude:** Opus 5.5 prompting guide, "Unattended agentic runs": treat a text-only end as a
  report; continue open items automatically, at most 2–3 times.
- **ArcNave now:** the user must press Continue.
- **How:** in the turn loop, when `finishReason === 'tool_limit'` and no blocker is stated,
  continue up to 2 times; cover with a fake-provider test.

### 7b. Large scanned PDFs take one extraction call per 30 pages (P0 from the scenario review)
- **Why pending:** not started; missed in the first draft of this handoff.
- **ArcNave now:** `TABLE_EXTRACTION_MAX_PAGES: 30` (`backend/src/config.ts:192`). A PDF over
  30 pages needs the model to ask for chunks under one `extractionId`, each a tool round out of
  16. A 150-page scanned statement also reaches the model as nothing (`readingFor` → `'none'`
  past 100 pages without text, `services/attachments/processUpload.ts:54`), so the tool is its
  only way in.
- **Claude:** no equivalent tool; it reads with generic code and strong vision (label the fix as
  ours). Check first whether items 4 and 5 alone keep a 150-page run inside the round limit.
- **How:** let one call extract every page (chunking inside the tool, bounded by time, with a
  progress event to the user), or return a job id the model polls once. Test with a fake
  vision provider on a 150-page fixture: one call, all pages, rounds used ≤ 4.
