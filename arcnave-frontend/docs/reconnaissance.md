## Boundaries

Live deep-research execution, attachment upload, destructive actions, subscription controls, all citation hover permutations, session expiry and real failure scenarios were not exhaustively exercised. UI references are observations, not a claim of a complete product audit. Exact fonts, CSS tokens and animation timing were not extracted; ArcNave's tokens are original design decisions. Existing personal content and logos are not copied.

## Architecture and design system

Routes: `/` new conversation; `/chat/:id`; `/chats`; `/projects`; `/project/:id`; `/artifacts`. Settings and search are accessible dialogs. Source, research, artifact and file are mutually exclusive contextual panels.

State: discriminated generation statuses idle/submitting/generating/stopped/complete/error; event-driven research stages; panel union closed/sources/research/artifact/file; project and chat records stored locally in this frontend demonstration. Mock adapter is replaceable with an async event stream. Mock responses and research are explicitly identified.

Typography: system sans navigation 14px, Georgia editorial heading 40px, 17px/1.75 reading text, 12–13px metadata, monospace code. Light paper #fafaf8, sidebar #f1f2ef, ink #282b30, accent #4b6378. Dark charcoal surfaces and desaturated blue accent. Spacing: 2/4/6/8/12/16/20/24/32/40/48/64px. Sidebar 252/64px; conversation/composer 760px; contextual panel 400px; header 64px. Radius 6/10/16px. Menus 6px padding, source rows 16px. Motion 160–220ms; reduced-motion support.

## Environment

Workspace was empty. Sites SKILL.md was readable, but the installed Sites scripts, setup references and hosting skill were absent; a search of the plugin cache confirmed this. Use standard Vite/React tooling as the build fallback. No deployment is claimed without successful hosting verification.
