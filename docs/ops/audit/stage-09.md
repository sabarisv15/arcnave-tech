## 4. Non-KEEP items
Order that keeps the app runnable: (1) intake / limits / safety fixes in the current synchronous path, (2) token count + sidecar + budget, (3) the state machine with an in-process runner, (4) the isolated parser service with OCR and extraction, (5) embeddings last (Stage 12).

### INTAKE / TYPES / LIMITS / SCAN / ZIP (safety first)
- Exact change: read the first 2 KB and check the signature against the extension (PDF, OOXML zip with the right content-types, OLE, PNG / JPEG / WebP / HEIC, audio containers, plain text); reject `.docm .xlsm .pptm` and `.doc .xls .ppt` (remove `.xls` from `ALLOWED`) with "Save it as DOCX / XLSX / PPTX and upload again"; reject password-protected PDFs / Office files with "remove the password"; trim `ALLOWED` to PDF, DOCX, XLSX, PPTX, CSV, TXT, MD, images (png jpeg webp heic/heif), audio (11 MIME types), ZIP (OQ9-3 decides the extras); per-type sizes from config (docs 100 MB, XLSX 50 MB, images 20 MB, audio 500 MB and <= 3 h by probe, ZIP 100 MB), <= 10 files per message, per-user upload rate; ZIP: list members first, caps (<= 20 files, <= 500 MB uncompressed, ratio), no nesting / symlinks / path traversal / encryption, each member goes through the same pipeline; ClamAV INSTREAM with limits >= our max and `AlertExceedsMax`, results `malware` / `scan_incomplete` (clamd as a container beside the API or parser service - infra); PDF JavaScript / OpenAction / Launch strip; images re-encoded (EXIF stripped) with pixel-bomb limits. Files: `services/storage.ts:335-483`, `services/attachments/processUpload.ts`, `routes/files.ts`, `config/numbers.ts` (+ N-ids), new `services/attachments/{sniff,zip,scan}.ts`. Port source: `arcnave.in:backend/apps/` (migrate / api upload checks) and `arcnave.in:parser/`.
- Option A (REWRITE intake in place; ClamAV behind a flag until the service exists): M · risk: legitimate files with odd MIME rejected; ClamAV needs a container (infra, owner OK) · breaks: `files.integration.test.ts` type tests; `.xls` users get the "save as" message.
- Option B (keep claimed-MIME allowlist, add only macro / legacy rejection): S · G1 "content-based" outcome not met, malware not scanned.
- Pick: A for sniff / rejection / limits / ZIP now; SCAN waits for OQ9-1 (the build plan defers ClamAV to Phase 5; ADR-0061 says locked decisions win).

Files: `routes/files.ts`, `db/schema.ts` + migration (status values, `error_code`, `sidecar_key`, `tokens_gemini`, `tokens_claude`, `file_pages` for per-page OCR engine / version), new `services/attachments/pipeline.ts`, frontend file card (other group).
