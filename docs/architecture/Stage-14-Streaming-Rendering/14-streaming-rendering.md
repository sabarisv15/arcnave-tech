## 0. Scope
Only what happens **on screen** (web + Android): progressive rendering of the stream, tables/code/math, citations + source viewer, file preview, artifact panel, HTML-preview safety, thinking panel, activity steps, notifications, Indian-script text, accessibility, long-chat performance, share page, and the **two admin consoles**. Transport/resume/background (Stage 5 F3, L1) stay locked. Safety categories Stage 16; numbers Stage 18.
